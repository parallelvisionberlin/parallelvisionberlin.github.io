# PV Lab 02

Moods opens first. Navigation: Gallery, Moods, Create, Profile. My Moods lives in Profile. Discovery uses the live curated catalogue. Choose a Mood, select a photo, continue through native sign-in, then review intensity and generation cost in Create. Nothing generates on selection.

Windows: run finish-lab02.ps1 -CheckOnly first. Run with -Build for one EAS preview build after the web deployment. Default performs checks only. The script verifies source hashes and the archive before submission. Install the resulting build over the existing app.

Device review: verify the iPhone photo picker, sign-in handoff between WebViews, background/foreground restoration, Gallery download/share and My Moods. Browser fixtures cannot certify native iOS file-store behavior.
