# Alejandro Molinari / Photo Work

An independent, editorial photography archive served from `https://parallelvisionlabel.com/photo-work/` within the existing GitHub Pages website.

## Galleries

- `after-hours`: four interiors.
- `nocturne`: five photographs taken in the forest at night, including the black-and-white blurred study. Working series name: **Nocturne**, overline **Night Flash**.
- `negative-space`: one black-and-white photograph.

All ten images were sourced from the user's `Alejandro Molinari - Photography Archive` folder in connected Google Drive. JPEG originals were copied byte for byte into `photo-work/images/`, without generative edits or aesthetic filters. File numbering follows the archive. The Drive originals remain in place.

To extend a gallery, add a new original JPEG under `images/<series>/` and append its path and truthful alt text to `series.js`. The carousel and counter update automatically. Hash links such as `/photo-work/#nocturne` open the chosen series. Keyboard arrows, swiping and the on-page arrows navigate photographs. The visitor does not need Google Drive access.

This is a standalone route deliberately isolated from PV LAB, Nina, and other active website branches. The artist page has one discreet link in the editorial archive. The photographs contain artistic nudity; ensure permission from identifiable adult subjects before public distribution. The page is link-accessible but uses `noindex` so search engines are asked not to index it.
