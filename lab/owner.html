ONE-TIME SERVER SETUP

Connect verified customer emails.

  1. In the Clerk dashboard ↗, locate the backend secret key for the production PV LAB application.
  2. In Cloudflare ↗, open Workers & Pages → parallel-vision-lab → Settings → Variables and Secrets. Add an encrypted secret named LAB_CLERK_SECRET_KEY.
  3. Save and deploy the secret, reload this page, then select Sync emails to backfill existing accounts.

Keep the key on the Worker. Never paste a secret into PV LAB's website code or this dashboard.
